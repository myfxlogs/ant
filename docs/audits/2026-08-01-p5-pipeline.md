# P5 回测管线逐行审计 — 2026-08-01

## 数据流

```
API handler → Engine.Run()
    │
    ├── OnInit → strategy.OnInit(ctx)
    ├── Loop over bars:
    │   ├── SetBar → broker.SetBar/SetBarTime/SetBarPrice
    │   ├── checkPendingOrders → fill limit/stop orders
    │   ├── checkSLTP → close positions hitting SL/TP
    │   ├── OnBar → strategy.OnBar → signal
    │   ├── dispatchSignal → broker.OrderSend/PositionClose
    │   └── computeEquity → equity point recorded
    ├── OnDeinit → strategy.OnDeinit
    └── Result: metrics + equity curve + trades → PG + SSE
```

## 逐环节审查

### 1. SimBroker (strategy/backtest/broker.go)

✅ Decimal 全链路: 所有价格/成交量/盈亏使用 decimal.Decimal。
✅ 佣金: 名义价值百分比，从 equity+balance 扣除。
✅ 滑点: 市价单买单 +slip、卖单 -slip。
✅ 保证金检查: `notional / leverage`。
✅ 隔夜费: 按实际持仓天数×swapRate×volume×contractSize。
✅ SL/TP 止盈止损: 买方向 high≥TP/low≤SL, 卖方向 low≤TP/high≥SL——正确。
✅ 限价单/止损单挂单触发: 逻辑正确。

### 3. Metrics (strategy/backtest/metrics.go)

✅ 最大回撤: 全 decimal 计算（peak - equity）/ peak——正确。
✅ 盈亏比: `totalProfit / totalLoss`，decimal——正确。
✅ 平均盈亏: decimal 除法——正确。

| 行 | 严重度 | 问题 |
|----|--------|------|
| 37 | 🔴 HIGH | `tr, _ := final.Sub(initial).Div(initial).Float64()` ——**总收益率经过 float64 往返**。`(final-initial)/initial` 用 decimal 精确计算，然后截断到 float64，然后再包装回 decimal（safeDecimal）。应直接: `m.TotalReturn = final.Sub(initial).Div(initial).String()` |
| 44 | 🔴 HIGH | `math.Pow(1+tr, 365.0/days) - 1` ——**年化收益率用 float64 幂运算**。`tr` 已经是 float64（从上一行截断），然后 `math.Pow` 进一步损失精度。对于 >100% 收益的多年度回测，年化误差可达 0.5-1 个百分点 |
| 87 | 🔵 LOW | float64 胜率——比例，可接受 |
