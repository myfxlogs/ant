# Agent 跨策略学习与经验积累 · 设计文档

> 来源：ADR-0024（"跨策略学习"）+ ADR-0025（"三层记忆"）
> 状态：Year 2 远期设计，当前不立项。等策略市场有足够实盘数据后启动。

---

## 背景

Phase 5 的 AI 迭代是**策略级**的——每个策略独立监控、独立优化。但 Agent 现在没有**跨策略**的学习能力。它每次面对一个新策略，都是从零开始——不知道"类似品种的类似策略通常用什么止损"、"什么样的策略结构在这个市场上更可能成功"。

## 三层学习模型

```
Layer 1 · 策略级（Phase 5 已做）
  └─ 单个策略衰减 → AI 监控 → 优化 → 新版本
  └─ 范围：一个策略 × 一个用户

Layer 2 · 用户级（当前未做）
  └─ 用户偏好的品种/周期/策略风格 → Agent 记住
  └─ 范围：一个用户 × 多个策略

Layer 3 · 平台级（本设计）
  └─ 所有策略的匿名化统计规律 → 公共知识库
  └─ 范围：全体用户 × 全体策略
```

---

## Layer 3 · 平台级学习 — 设计

### 学什么（从匿名化实盘数据中提取）

| 知识类型 | 示例 | 数据来源 |
|---------|------|---------|
| 品种×周期规律 | "H1 EURUSD 上带止损的趋势策略胜率 45%，M15 上 38%" | `marketplace_live_performance` |
| 结构模式规律 | "使用 EMA 双均线交叉的策略中，加 MACD 过滤的策略夏普高 0.3" | `strategy_templates` + 回测数据 |
| 风险因子规律 | "止损 <20 点的策略平均存活 3 周，止损 >50 点的存活 8 周" | 实盘 + 衰减记录 |
| 衰减模式规律 | "马丁类策略通常在 6-8 周后衰减，趋势类在 12-16 周" | `strategy_optimization_tasks` |

### 怎么学

```
实盘数据（已匿名化）
      │
      ▼
pgvector 嵌入
  └─ 策略源码 + 回测metrics + 实盘曲线 → 向量
  └─ 相似的策略向量在空间中靠近
      │
      ▼
聚类分析
  └─ 相似的策略自动归组
  └─ 组内对比：哪类参数/结构表现更好
      │
      ▼
知识蒸馏
  └─ LLM 总结每一组的知识 → 结构化存储
  └─ 输出格式：{"pattern": "...", "finding": "...", "confidence": 0.82}
      │
      ▼
公共知识库（pgvector）
  └─ Agent 在帮助新策略时注入相关知识
  └─ 不做自动策略竞争——只做引导
```

### 知识如何使用

**在策略生成时**：Agent 收到"帮我做一个 EURUSD 趋势策略" → 查询知识库："H1 趋势策略在这个品种上最有效的信号组合是 EMA 交叉 + RSI 过滤" → 在生成 prompt 中注入这个知识。

**在衰减检测时**：策略夏普下滑 → 查询知识库："类似策略的衰减通常是因为市场转震荡" → 给出更精准的诊断。

**在策略市场中**：买方浏览策略时 → 展示"基于 200+ 同类策略的分析，此策略的风险因子处于健康区间"。

## 数据隔离边界（红线）

| 可以学 | 不可以学 |
|--------|---------|
| 匿名化的统计规律 | 特定提供者的策略源码 |
| 品种×周期的通用模式 | 提供者 A 的参数直接给提供者 B |
| 风险因子的统计分布 | 任何可追溯到具体策略的数据 |
| 结构模式的流行度统计 | 原始收益率数据（避免反推策略逻辑） |
