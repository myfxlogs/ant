## 施工原则（我的决策）

1. **救命优先**：防线 B 恒等类（判决型，零误报，抓致命错误）> 防线 A（编译期，独立）> 统计类（提示型，不阻断，低优）。
2. **设计原则**：所有恒等类不变量为**纯函数**（`func(result) *BlindSpot`），统一收集到 `buildBacktestResponse` 的不变量列表，统一接入 `IsReliable` 闸门。理由：ADR 要加多个不变量，纯函数可组合（成交手数>0 已验证此模式），加新不变量 = 加一个函数 + 列表加一行。
3. **碰钱逻辑我亲自把关**：恒等类不变量、防线 A 修提案 bug #4（编译器核心）——这些我亲自 review + 构造对抗 case，不只看 GLM 产出。GLM 无责，我担全责。
4. **节奏**：日常 GLM 单做 + 我验收（省成本）；碰钱/复杂任务 A/B 抽查（保压力、验退化）。
5. **每任务闭环**：我写 spec → GLM 施工 → 我 5 维（意图/可演进/测试质量/防御/克制）+ 对抗验收 → 合并或返工（决策在我）。
