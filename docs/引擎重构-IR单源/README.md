# 引擎重构 · IR 单源

本目录是 MQL 策略引擎"IR 单源"重构的**权威施工规格**，作为施工方（DeepSeek / GLM）的唯一指导依据。

## 文档清单

| 文档 | 用途 |
|------|------|
| `01-架构决策.md` | 为什么做、决策结论、目标态拓扑（ADR 性质，不可推翻的方向） |
| `02-施工工单.md` | 任务拆分、文件锚点、改动内容、验收标准、依赖与优先级 |
| `03-硬约束与验收.md` | 项目硬约束（AGENTS.md）、全局回归清单、里程碑 |

## 一句话方向

> **`interp.IR` 是 MQL 策略的唯一权威表示。执行、覆盖度报告、Go 导出三者全部消费同一个 IR。有损的模式识别器（`StrategyIntent`）从执行与报告路径上彻底剥离。**

## 施工纪律

1. 动工任何任务前，先读完 `01-架构决策.md`，理解方向，不得偏离。
2. 每个任务动工前执行复用核对：`bash scripts/cap.sh <符号>`，在 PR 描述给出 `REUSE:` 或 `NEW:` 结论。
3. 严格遵守 `03-硬约束与验收.md` 的项目红线。
4. 一次提交一个任务 scope，按 `02-施工工单.md` 的依赖顺序推进。
